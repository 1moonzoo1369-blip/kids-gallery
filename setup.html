업로드 비밀번호 만들기 (한 번만)

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 이 그림앨범 레포만 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. Expiration은 가능한 길게(최대 1년, 또는 No expiration) — 만료되면 이 페이지에서 다시 등록

토큰은 아래 가족 비밀번호로 암호화되어 레포의 js/config.js에 저장돼요. 원래 토큰은 어디에도 그대로 남지 않아요. 누구나 암호화된 값을 볼 수 있으니 10자 이상, 추측하기 어려운 비밀번호를 써 주세요. 남편분께는 이 비밀번호만 알려주면 돼요.
